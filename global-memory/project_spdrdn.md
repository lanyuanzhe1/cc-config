SPDRDN 是一个基于 RDN 架构的偏振图像超分辨率项目。项目包含四个分支，使用不同的偏振参数作为辅助损失函数训练同一个 RDN 模型。

**Why:** 通过对比不同偏振损失函数（AoP/DoLP/DoCP/DoP）的效果，找到最优的辅助训练策略。

**How to apply:** 当用户提到训练、分支、偏振、AOP/DOCP/DOLP/DOP 时，参考此项目上下文。云服务器连接信息在 CLOUD_SERVER_AGENT_HANDOFF.md 中。
